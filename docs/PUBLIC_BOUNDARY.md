# Public boundary

Aether is readable by anyone. Write as if a stranger will clone it tonight.

## Publish

- Architecture sketches and proposed interfaces
- Contributor, security and conduct policy
- Schemas with dummy values
- Public agent **roles** already used on sibling public repos (Lumia / Elara, Lyra, Xen, Elysium)
- Operator public identity: Esslinger & Co., GitHub `digitaldesignerjazz`, Hannover as project origin

## Do not publish

- Private correspondence
- Private persons and household or family internals
- Live keys, tokens, seeds, overlay setup material, wallet files
- skilllogin state, private mempool or receipt dumps
- Copies of private repositories (avalon-os, lumiaos, ElysiumOS and similar)

If a change cannot be written without one of the forbidden items, it does not belong in this repository.
