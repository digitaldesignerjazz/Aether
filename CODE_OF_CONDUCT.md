# Code of Conduct

Aether is a public workshop, not a private salon.

- Be precise. Prefer specs over heat.
- Do not harass, doxx or drag private persons into the field.
- Do not dump credentials "for context".
- Disagreement about architecture is welcome. Contempt is not.
- Maintainers may hide or remove material that crosses the public boundary.

This document is a working conduct note for a seeded repository. It can be replaced with a longer standard later without changing the boundary.
