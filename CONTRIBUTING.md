# Contributing to Aether

Thank you for approaching the field.

Aether is public. Assume every issue, comment and commit is readable by strangers.

## Before you start

1. Read [docs/PUBLIC_BOUNDARY.md](docs/PUBLIC_BOUNDARY.md).
2. Read [docs/VISION.md](docs/VISION.md).
3. Open an issue for anything larger than a typo.

## How to work

- Branch from `main`.
- Keep commits small and reviewable.
- Do not force-push `main`.
- Do not commit secrets, live keys, wallet material, overlay tokens or private state.
- Do not name private persons.
- Use placeholder values in schemas (`alice-node`, `0x00`, `example.invalid`).

## Pull requests

- Target `main`.
- Describe the change and the public surface it touches.
- Note any sibling-repo interaction (LuminaCyberspace, lumina-network) without copying private trees.

## Language

English for code, specs and issue titles. German is welcome in discussion when it stays public-safe.
