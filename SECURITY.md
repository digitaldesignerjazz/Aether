# Security Policy

## Public field rule

Do **not** file secrets, keys, seeds, tokens or private personal data in GitHub issues.

If you believe you found a vulnerability in Aether or a sibling public repository:

1. Do not open a public issue that contains exploit details or credentials.
2. Contact the operator through GitHub security advisories on this repository when enabled, or via the account that owns `digitaldesignerjazz`.
3. Include only what is needed to reproduce. Redact keys.

## Scope

In scope: public specs, sample code and published interfaces in this repository.

Out of scope: private overlay deployments, unpublished OS trees, third-party services, social-engineering reports that name private persons.
